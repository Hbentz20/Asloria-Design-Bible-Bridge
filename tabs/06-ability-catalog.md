# Ability Catalog

Every Path ability is filed here with the Established data fields (Design Bible, Progression: "Ability data fields"). The catalog comes before the tree: Placement fields stay Open or Proposed until the holistic review of all three Paths places each ability. Universal Expression uses (Crushing Blows, Driving Strike, Shoulder the Blow, Overwhelm) are Expression rules, not Path abilities, so they live in the Expressions section rather than here.

**How to file.** Copy the entry template below, fill every field you can from the Design Bible, and write "Open" rather than guess. Placement, Cost and Rules are the minimum for an entry to count as filed. When a rule changes, update the entry and add a dated line to its change history; never silently overwrite. IDs are permanent: SW (Sword), SO (Sorcerer), WA (Wanderer), CV (convergence), numbered in filing order. The prefix records the Path an ability was first catalogued under; if the ability later moves, its ID stays and only its Path changes. A removed ability keeps its ID, which is never reused.

## Entry template

- **Identity:** ID · name · status · origin · flavor line
- **Placement (Layer 1):** Path · branch · tier · node size · connections
- **Requirements (Layer 2):** attribute thresholds · required abilities · convergence requirements
- **Cost:** XP cost · resource cost (and whether it prompts the Expression Die) · uses and refresh
- **Rules:** action type · Instant or Committed (and completion condition) · trigger · target and range · effect · duration · failure or interruption · interactions
- **Tags:** Gain / Hold / Release / Crest · conditions applied · keywords
- **Tracking:** design intent · sim status · decision-log date · change history
